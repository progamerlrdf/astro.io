Astro.io

Mange les astéroïdes pour gagner de l’XP, améliore ton vaisseau et détruis les autres pilotes.
Tablette : stick gauche = déplacer, stick droit = viser et tirer. Clavier : ZQSD/WASD + souris, espace = tir, C (maintenir) = tir chargé.
Manette : stick gauche = déplacer, stick droit = viser, RT = tir, A (maintenir) = tir chargé, X = boost, B = bombe (désactivée pendant le tir), Start = jouer.
